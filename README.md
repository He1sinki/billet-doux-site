# Site de Billet Doux

La page d’accueil et la politique de confidentialité de Billet Doux, servies par GitHub Pages :
https://he1sinki.github.io/billet-doux-site/

- `index.html` : l’accueil ;
- `confidentialite.html` : la politique de confidentialité (français, puis anglais à `#en`) ;
- `polices/` : Gloock, Kalam et Figtree (SIL Open Font License, licences jointes), réduites aux caractères latins et
  servies par le site lui-même, sans appel à un autre service.

Pas de cookie, pas de script, pas de mesure d’audience. Le code de l’app est dans un dépôt privé.
